## 历史数据兼容与修复

2023—2025 年的官网历史数据中实际出现过以下异常：

- `/compound/heroRecord` 的 `role` 为空；
- 英雄 ID 为 0 的空身份占位记录；
- 某名替补选手 `matchCount=0`，但 `boCount>0` 且确有逐局数据；
- 个别逐局选手记录缺失；
- `/compound/matchDetail` 返回两支 `teamId=0`、无选手的官方空占位局。

采集器现会按需读取比赛详情补充分路和缺失行；英雄 ID 为 0 时，只允许通过官网英雄聚合的 Pick、胜场、K/D/A 剩余量进行唯一精确恢复。无法唯一对账的数据会整批拒绝发布。选手记录仅在 `matchCount` 与 `boCount` 同时为 0 时才按未登场过滤。处理规则版本已纳入内容哈希，规则升级后可对未变化的官网原文重新发布修正数据。
